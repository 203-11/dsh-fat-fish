# dsh-fat-fish

[English](README.md) | 中文

一个可拖动的蓝发人鱼桌宠，运行在 DeepSeek Harness Web UI 中。它会提醒你喝水、起身走走，记录每天完成次数，并根据频率冒出不同的内心戏。

![大肥鱼桌宠](assets/default-avatar.webp)

## 功能

- 漂浮、可拖动的桌宠，带浮动、眨眼、气泡和向前游动效果。
- 喝水与走动提醒：可调整间隔、暂停/继续、稍后提醒、一键记录。
- 今日喝水/走动次数与最近历史记录。
- 自定义形象：支持 PNG、JPG、WebP、GIF，本地缩放到 1024px，仅保存在当前浏览器。
- 形象大小可在 60%–200% 之间自由调整，默认 165%。
- 根据当天频率生成的内心戏、热梗台词，以及连续点击触发的吐槽。
- 使用 Web Audio 实时合成的原创曼波风提示音，不包含第三方录音或采样。
- 设置、历史、形象、大小和位置通过 `localStorage` 持久化。

## 要求

- 支持 `shell.overlay` 的 DSH Web（已在 DSH `0.2.1-rc.3` 测试）。
- 无需构建步骤，也不依赖额外服务。

## 安装

该包是可直接安装的 DSH bundle。上架插件市场后请在 DSH 插件市场中安装；本地开发时可通过 DSH 插件管理器安装此目录。

## 音效与隐私

- 提示音由 Web Audio 在运行时生成，是原创的曼波风小旋律，不复刻任何现有录音或歌曲。
- 提醒计划、每日记录、设置、形象、大小和位置都保存在浏览器 `localStorage` 中；插件不会为这些功能发起网络请求。

## 开发

仓库根目录就是插件包。没有构建步骤：修改 `client.js` 和 locale 文件后，通过 DSH 插件管理器安装目录即可。
